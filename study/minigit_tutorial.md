# MiniGit 파이썬 코드 현미경 학습 교재 🔬

이 문서는 파이썬 문법이 아직 낯선 분들을 위해 `minigit` 프로젝트의 코드를 한 줄 한 줄 현미경처럼 분석하는 교재입니다. 파이썬의 기본 문법과 함께, 이 프로그램이 어떻게 동작하는지 배워봅시다!

---

## 1. 첫걸음: 클래스(Class)와 객체(Object)의 세계

`minigit` 코드를 읽다 보면 가장 많이 등장하는 단어가 바로 `class`입니다. 파이썬에서 가장 중요한 **객체 지향 프로그래밍**의 핵심이죠.

### `__main__.py` 톺아보기

```python
class MiniGitCLI:
    def __init__(self) -> None:
        self.repo: Repository = Repository()
```

#### 🔍 문법 현미경 분석

> [!NOTE]
> **`class MiniGitCLI:`**
> - **`class`**: 파이썬에게 "지금부터 붕어빵 틀(설계도)을 만들게!"라고 알려주는 마법의 단어입니다.
> - **`MiniGitCLI`**: 우리가 만든 붕어빵 틀의 이름입니다. 이름 뒤에 콜론(`:`)을 붙여서 "이제부터 이 틀의 내용을 설명할게"라고 선언합니다.

> [!TIP]
> **`def __init__(self) -> None:`**
> - **`def`**: "함수를 정의(define)할게!"라는 뜻입니다. 함수란 어떤 동작을 수행하는 코드 블록입니다.
> - **`__init__`**: 파이썬에서 특별하게 취급하는 함수 이름입니다. 양쪽에 밑줄 두 개(`__`)가 있죠? 이는 이 클래스로 붕어빵(객체)을 **처음 딱 구워낼 때 자동으로 한 번 실행되는 초기화 설정 버튼**입니다.
> - **`self`**: 붕어빵 틀에서 구워진 **붕어빵 자기 자신**을 뜻합니다. 클래스 안의 함수들은 무조건 첫 번째 재료로 `self`를 받아야 자신의 데이터를 만질 수 있습니다.
> - **`-> None`**: 타입 힌트(Type Hint)입니다. "이 함수는 끝나고 아무것도 반환하지 않는다(None)"라는 뜻을 파이썬과 다른 개발자들에게 알려주는 메모지입니다.

> [!IMPORTANT]
> **`self.repo: Repository = Repository()`**
> - **`self.repo`**: "내(`self`) 안에 `repo`라는 이름의 주머니를 만들게!"
> - **`: Repository`**: 콜론(`:`)은 역시 타입 힌트입니다. "이 `repo` 주머니 안에는 `Repository`라는 종류의 물건만 들어갈 거야"라고 명찰을 달아준 것입니다.
> - **`=`**: 오른쪽의 결과를 왼쪽 주머니에 집어넣으라는 뜻입니다. (같다는 뜻이 아님!)
> - **`Repository()`**: `Repository`라는 또 다른 붕어빵 틀(클래스)을 불러와서, 괄호 `()`를 붙여 새로운 붕어빵(객체)을 하나 뿅! 만들어냅니다.

## 2. 함수(Function)와 타입 힌트(Type Hint)

### 문자열을 리스트로 바꾸는 마법

```python
def parse_input(self, user_input: str) -> List[str]:
    clean_input: str = user_input.strip()
    return clean_input.split()
```

#### 🔍 문법 현미경 분석

1. **`user_input: str`**
   - 사용자로부터 문장(예: `"commit hello"`)을 입력받을 텐데, 이 데이터는 무조건 문자열(`str`, String의 약자)이어야 한다는 힌트입니다.

2. **`-> List[str]`**
   - 이 함수가 마법을 부리고 나면, 결과물로 **"문자열들이 들어있는 리스트(List)"**를 뱉어낼 거라는 뜻입니다. 예: `["commit", "hello"]`

3. **`clean_input: str = user_input.strip()`**
   - `strip()`은 파이썬 문자열이 기본적으로 가지고 있는 내장 기능입니다. 양쪽 끝에 있는 쓸데없는 띄어쓰기(공백)를 깔끔하게 잘라줍니다.

4. **`return`**
   - 함수의 핵심! "이 결과물을 나를 부른 곳으로 다시 돌려보내 줘!"라는 뜻입니다. `split()`은 띄어쓰기를 기준으로 문장을 단어 단위로 쪼개서 리스트로 만들어줍니다.

## 3. 조건문 (if 문)

```python
if len(args) < 1:
    return ErrorMessages.INVALID_COMMIT
```

#### 🔍 문법 현미경 분석

> [!NOTE]
> - **`if`**: "만약에 ~라면"
> - **`len(args)`**: `len`은 length(길이)의 약자로, `args`라는 리스트 안에 단어가 몇 개나 들어있는지 숫자로 세어줍니다.
> - **`< 1`**: 그 숫자가 1보다 작다면 (즉 0개라면). 사용자가 아무 명령어도 안 쳤다는 뜻이겠죠!
> - 이 조건이 참(True)이면 아래에 들여쓰기 된 `return` 줄이 실행되어 에러 메시지를 뱉어내고 함수가 그 즉시 끝납니다.
